# KnowledgeBaseAI

React + TypeScript + Vite приложение для визуализации и управления графом знаний.


### 🔍 Фильтрация и Легенда (ExplorePage)

Для управления сложностью графа реализован механизм динамической фильтрации по типам.

1.  **Авто-обнаружение типов:**
    *   При загрузке данных (`viewport`) мы анализируем все типы узлов (`kind`).
    *   Используется `useMemo` для формирования списка уникальных категорий, присутствующих в текущем виде.
2.  **Интерфейс фильтра:**
    *   В верхней панели добавлен селектор `KBSelect` (Kind).
    *   Пользователь может выбрать конкретный тип (например, "Resource") или оставить "All".
3.  **Реактивная перерисовка:**
    *   При смене фильтра массив узлов мгновенно обновляется.
    *   `vis-network` удаляет скрытые узлы с Canvas, сохраняя при этом позиции и масштаб камеры, что обеспечивает бесшовный визуальный переход.

## 🛠️ Запуск и Разработка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера (доступен на http://localhost:5173)
npm run dev
```

## ⚠️ Важные технические моменты

*   **useRef:** Используется для хранения ссылок на `network` (инстанс графа) и `cameraRef`, чтобы иметь доступ к актуальным данным внутри замыканий `useEffect` и таймеров, не вызывая лишних перерисовок.
*   **Race Conditions:** При инициализации `vis-network` используется `setTimeout(..., 100)`, чтобы дать браузеру время отрисовать контейнер (DOM) перед тем, как двигать камеру. Без этого координаты могут быть некорректными.

## 🚀 Changelog (Эпик 2: Модуль "Explore")

Реализованы ключевые функции для превращения прототипа в полноценный инструмент анализа.

### [EXP-03] Фильтрация по типам (Kind)
*   **Задача:** Предоставить инструмент для быстрой очистки графа от "шума", оставляя только нужные типы узлов (например, только навыки или ресурсы).
*   **Решение:**
    *   Реализовано динамическое извлечение всех доступных типов (`kind`) из текущего набора данных (`viewport`) через `useMemo`.
    *   Добавлен компонент фильтрации `KBSelect` в панель инструментов страницы.
    *   Внедрена реактивная фильтрация: при смене типа в селекте граф мгновенно перерисовывается, скрывая лишние узлы, но сохраняя структуру и позиции оставшихся.
