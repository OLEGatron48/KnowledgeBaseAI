# Отчет об изменениях (Changelog) — KnowledgeBaseAI

## 🚀 Эпик 2: Модуль "Explore" и Интеграция ИИ

В рамках текущего этапа разработки была проведена масштабная работа по улучшению визуализации графа, интеграции ИИ и приведению кода фронтенда к техническим стандартам (SOLID, DRY, DoD).

### 1. Визуализация и Состояние (ExplorePage)
- **Сохранение состояния:** Внедрен `GraphContext`. Теперь при навигации по приложению камера и позиции узлов "замораживаются". При возврате на страницу Explore пользователь видит граф ровно в том же состоянии, в котором оставил.
- **Оптимизация рендеринга:** Устранены лишние перерисовки графа при открытии чата или смене темы. Использованы `React.memo` и `useCallback`.
- **Empty States:** Добавлена визуализация "Пустого графа" (иконка + текст), если API не вернул данных.

### 2. Детализация узлов (NodeDetailsSidebar)
- **Динамические данные:** Реализована загрузка подробностей об узле (связи, свойства) "на лету" через API.
- **Улучшенный UI:** 
  - Сетка свойств (Property Grid) теперь выглядит эстетично.
  - Добавлена проверка на наличие свойств: если их нет, выводится сообщение "Нет дополнительных свойств".
  - Списки связей (входящие/исходящие) разделены визуально.

### 3. ИИ Ассистент и Чат
- **Redux Integration:** Все сообщения и состояние чата теперь управляются через `Redux Toolkit`. Это позволяет сохранять контекст диалога при переходах между страницами.
- **Индикатор загрузки (DoD):** Добавлено состояние `isSending`. Пока ИИ генерирует ответ, кнопка отправки заблокирована и отображает индикатор.
- **KBSelect Component:** Реализован кастомный выпадающий список для выбора действий ИИ (Ответ, План и т.д.), работающий по принципу `dropUp` (открывается вверх), чтобы не выходить за границы окна чата.

### 4. Технический аудит и Качество (SOLID, DRY, DoD)
- **Удаление Hardcode:** Тестовые узлы вынесены в `appConfig.ts`. Настройки UI (размеры, отступы) вынесены в `uiConfig.ts`.
- **Refactoring (SOLID):** Логика подготовки данных для `vis-network` полностью вынесена в `src/utils/graphUtils.ts`. Компонент `ExplorePage` теперь отвечает только за отображение.
- **Типизация:** 
  - Полностью удалены `any` во всех измененных частях кода.
  - `HttpError` соответствует стандарту `{ status, message, details }`.
  - Модели `GraphNode` и `GraphEdge` приведены к проектному стандарту.
- **CSS Architecture:** Основные стили разметки вынесены в `index.css`. Удалено более 100 строк инлайновых стилей из `App.tsx`.
